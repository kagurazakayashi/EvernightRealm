# 長夜幻境（EvernightRealm）

> 在自己的機器上，為你的小圈子搭建一座私密的虛擬世界——管理活動、扮演角色、交換虛擬資產。

[English](./README.md) · [簡體中文](./README.zh-CN.md) · [繁體中文（臺灣）](./README.zh-TW.md) · [日本語](./README.ja-JP.md)

## 這是什麼？

長夜幻境是一個自主部署、離線優先的平臺，面向小規模玩家群體：一起推進沉浸式活動、扮演角色、交易虛擬資產——全部在區域網內完成，不需要公網、雲賬號或遙測。

## 功能規劃（開發中）

- **沉浸式活動**：為你的群體編排場景、階段與事件
- **角色與身份**：玩家、NPC 與管理員的角色，共處一個私密世界
- **虛擬資產**：物品有真實歸屬，交易可審計
- **私密聊天**：訊息只留在你自己的伺服器上
- **離線優先**：一切執行在你自己的機器上，不依賴雲服務

## 當前狀態

長夜幻境正在積極開發中，尚未釋出穩定版本。服務端現在可以建置為**單一可執行檔**：同一個連接埠同時提供網頁介面（目前是可切換語言、可偵測伺服器連通性的應用殼，業務功能仍在開發）與 API 端點，瀏覽器直接開啟它的位址即可使用，不需要另外部署靜態服務。

## 釋出後的使用方式（規劃）

- 一人在這臺機器（Windows 或 Linux）上託管服務端
- 其他人在同一區域網內用瀏覽器加入
- 無需第三方註冊；資料只儲存在主機上
