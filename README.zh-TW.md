# 長夜幻境（EvernightRealm）

> 在自己的機器上，為你的小圈子搭建一座私密的虛擬世界——管理活動、扮演角色、交換虛擬資產。

[English](./README.md) · [簡體中文](./README.zh-CN.md) · [繁體中文（臺灣）](./README.zh-TW.md) · [日本語](./README.ja-JP.md)

## 這是什麼？

長夜幻境是一個自主部署、離線優先的平臺，面向小規模玩家群體：一起推進沉浸式活動、扮演角色、交易虛擬資產——全部在區域網內完成，不需要公網、雲賬號或遙測。

## 功能規劃（開發中）

- **沉浸式活動**：為你的群體編排場景、階段與事件
- **角色與身份**：玩家、NPC 與管理員的角色，共處一個私密世界
- **虛擬資產**：物品有真實歸屬，交易可審計
- **私密聊天**：訊息只留在你自己的伺服器上
- **離線優先**：一切執行在你自己的機器上，不依賴雲服務

## 當前狀態

服務端另提供一個維運命令來產出**一致性備份包**：單檔資料庫快照（服務執行中即可產出，不是複製活躍的 WAL 主檔），連同設定檔與媒體／文件／上傳目錄，逐檔記錄大小與 SHA-256 並附一份清單。與之配套的 `restore` 命令能把這份包還原成一個**全新的空資料目錄**：逐檔依清單重算校驗和，落地前後各讀一次快照的資料庫事實並與清單對照，**不覆蓋任何既有目錄**（要覆蓋請先自行備份該目錄），拒絕比目前執行檔更新的資料庫結構版本，並把這次還原本身寫成一筆伺服器端審計記錄。備份包還不能加密，舊包也不會自動清理。

一次性 Root 初始化**只有本機命令這一條入口**：

    evernight-server init-root --password-stdin --data-dir <資料目錄>

它從標準輸入讀口令（前兩行是口令與確認），把 Argon2id 編碼寫進該資料目錄的 `config.yaml`，不輸出任何秘密——不寫明文，也不會自動產生或顯示一個「出廠口令」。交出伺服器最高權限的授權依據是「能在伺服器主機上執行命令」，所以這一步不開任何 HTTP 端點、不佔連接埠；CORS、客戶端自報的位址、介面上隱藏按鈕都不構成授權。服務持有單寫入實例鎖時、`ER_SECURITY_ROOT_PASSWORD_HASH` 蓋著檔案時、或審計表尚未建立時，本命令一律拒絕；寫成功之後也不會再開放第二次——覆蓋既有 Root 不是一條支援的路（換口令要走在已認證之下的改密流程，尚未開發）。只讀的 `evernight-server root-status` 能回答「現在有沒有 Root」，它不建立也不改動任何檔案，而且只回答這麼多：不給出配置路徑、雜湊或任何引導秘密。成功與拒絕都會寫進 Root 審計表，且不記錄口令。

首次啟動的介面要如實顯示「還沒初始化」，服務端因此另外回答一個唯讀的 `GET /root/init-status`：只有設定檔是否存在、是否已有 Root 憑據、環境變數覆蓋是否處於設定狀態這三個布林值，不回傳路徑、長度或任何憑據片段，也不寫資料庫、不寫審計。它把「有沒有」說出來，不說「怎麼改」——初始化 Root 仍然只有 `init-root` 這一條在伺服器本機上執行的通路。

長夜幻境正在積極開發中，尚未釋出穩定版本。服務端現在可以建置為**單一可執行檔**：同一個連接埠同時提供網頁介面（目前是可切換語言、可偵測伺服器連通性的應用殼，業務功能仍在開發）與 API 端點，瀏覽器直接開啟它的位址即可使用，不需要另外部署靜態服務。

## 釋出後的使用方式（規劃）

- 一人在這臺機器（Windows 或 Linux）上託管服務端
- 其他人在同一區域網內用瀏覽器加入
- 無需第三方註冊；資料只儲存在主機上

## 從原始碼建置

Windows 執行檔的圖示是產生出來的、不納入版本控制：`cmd/evernight-server/resource_windows_*.syso` 由 `assets/icons/EvernightRealmBackendRounded.ico` 推導。全新複製的倉庫在編譯前先執行

    python tools/icons/generate_icons.py

否則產生的執行檔沒有圖示，而 `go build` 不會報錯。`python tools/icons/generate_icons.py --check` 只核對現況，不寫入任何檔案；詳見 `tools/icons/README.md`。
