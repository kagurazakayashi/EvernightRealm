# 长夜幻境（EvernightRealm）

> 在自己的机器上，为你的小圈子搭建一座私密的虚拟世界——管理活动、扮演角色、交换虚拟资产。

[English](./README.md) · [简体中文](./README.zh-CN.md) · [繁體中文（台灣）](./README.zh-TW.md) · [日本語](./README.ja-JP.md)

## 这是什么？

长夜幻境是一个自主部署、离线优先的平台，面向小规模玩家群体：一起推进沉浸式活动、扮演角色、交易虚拟资产——全部在局域网内完成，不需要公网、云账号或遥测。

## 功能规划（开发中）

- **沉浸式活动**：为你的群体编排场景、阶段与事件
- **角色与身份**：玩家、NPC 与管理员的角色，共处一个私密世界
- **虚拟资产**：物品有真实归属，交易可审计
- **私密聊天**：消息只留在你自己的服务器上
- **离线优先**：一切运行在你自己的机器上，不依赖云服务

## 当前状态

长夜幻境正在积极开发中，尚未发布稳定版本。服务端现在可以构建为**单一可执行文件**：同一个端口同时提供网页界面（目前是可切换语言、可探测服务器连通性的应用壳，业务功能仍在开发）与 API 端点，浏览器直接打开它的地址即可使用，不需要另外部署静态服务。

服务端还提供一个运维命令来产出**一致性备份包**：单档数据库快照（服务运行中即可产出，不是复制活跃的 WAL 主档），连同配置与媒体／文档／上传目录，逐档记录大小与 SHA-256 并附一份清单。恢复入口是下一步，所以这份备份目前只能人工核对。

## 发布后的使用方式（规划）

- 一人在这台机器（Windows 或 Linux）上托管服务端
- 其他人在同一局域网内用浏览器加入
- 无需第三方注册；数据只保存在主机上
